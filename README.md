## 📡 درباره پروژه

**Ayhan Meli Shecan** یک ریپازیتوری متن‌باز برای جمع‌آوری و انتشار سابسکریپشن‌های Xray/V2Ray است.

این پروژه با هدف ایجاد یک منبع متمرکز برای دسترسی به لیست‌های سابسکریپشن، دسته‌بندی پروتکل‌ها و مدیریت آسان‌تر منابع مرتبط توسعه داده شده است.

### ✨ ویژگی‌ها

* 🚀 بروزرسانی مداوم منابع
* 📂 دسته‌بندی بر اساس پروتکل
* 🌍 سازگار با کلاینت‌های مختلف
* 🔄 سابسکریپشن‌های آماده استفاده
* 🛠 متن‌باز و قابل توسعه
* 📱 پشتیبانی از چندین پلتفرم
